# Synthetic submission example — tests and documentation only

This is a completely synthetic, redistributable test fixture. It is **not** a
published biological library, does not represent a real source dataset, and
must never be published as a gene-set library.

It demonstrates the new-library submission package contract: declarative
source/input metadata, thin wrapper dispatch, a smoke-mode reproduction entry
point, and expected output records. The wrapper only simulates its declared
DIG command; it performs no biological computation.
