# Source assessment

The legacy GMT is never an HZ1 input. The original raw `MW_gene_metabolite.tsv` described by the historical notebook is unavailable in its repository. The downloadable Harmonizome edge list is selected because it is a processed public descendant with the required Gene, Gene ID, Metabolite, and Metabolite ID fields. It is version-pinned locally for each full run; the manifest records the resulting checksum.
