Existing GlyGen genesets are in GlyGen_Glycosylated_Proteins_2022.gmt on DCC matrix page https://info.cfde.cloud/dcc/GlyGen#XMT. There are 338 genesets

There is a Harmonizome page for GlyGen: https://maayanlab.cloud/Harmonizome/dataset/GlyGen+Glycosylated+Proteins
There are 1910 gene sets in Harmonizome.

Harmonizome processing script uses three files: 
human_proteoform_citations_glycosylation_sites_unicarbkb.csv
human_proteoform_citations_glycosylation_sites_harvard.csv
human_proteoform_citations_glycosylation_sites_glyconnect.csv

these files are available from GlyGen (https://data.glygen.org/): 
https://data.glygen.org/GLY_000138   ..._glycosylation_sites_unicarbkb.csv
https://data.glygen.org/GLY_000513   ..._glycosylation_sites_harvard.csv
https://data.glygen.org/GLY_000483   ..._glycosylation_sites_glyconnect.csv
