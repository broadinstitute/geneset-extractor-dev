# KidsFirst Pediatric Cancer Gene Sets

Author: kyuryung

Differential expression analysis and gene set extraction for pediatric cancers using KidsFirst PBTA, CBTN, and GTEx data.

---

## Data Sources

### Tumor cohorts

| Cohort | Disease | N |
|--------|---------|---|
| KF-TALL | T-cell Acute Lymphoblastic Leukemia | 1,026 |
| KF-NBL | Neuroblastoma | 207 |
| KF-ESGR | Ewing Sarcoma | 77 |
| KF-MMC | Acute Myeloid Leukemia | 58 |
| CBTN | Pediatric brain tumors (7 diagnoses) | 60–408 per diagnosis |

Source: KidsFirst Data Resource Center and Children's Brain Tumor Network (CBTN). RNA-seq quantified with RSEM, hg38/GENCODE.

### Normal reference cohorts

Pediatric normal RNA-seq is not available for most of these tumor types. GTEx v10 adult tissue is used as the normal reference. KF-CHDALL (Down syndrome pediatric blood, N=400) is used as an additional internal control for T-ALL to allow pipeline-matched and age-matched comparison.

| GTEx tissue | Used for |
|-------------|----------|
| Whole Blood | T-ALL, AML |
| Adrenal Gland | Neuroblastoma |
| Muscle - Skeletal | Ewing Sarcoma |
| Brain - Cortex | CBTN brain tumors |

GTEx donors are adults (ages 20–79). GTEx is quantified with RNASeQC; count-level integration with RSEM is performed at the raw count level on shared hg38 gene coordinates.

## Gene Set Versions

### Version 1 — harmonizome (DIG standard)

Generated by `run/sbatch_03_extract_genesets.sh` using the `rna_deg_multi` harmonizome preset.

- Criteria: padj < 0.05, |logFC| ≥ 1
- Includes both upregulated (`__pos`) and downregulated (`__neg`) sets per comparison
- Size: all threshold-passing genes (threshold-based, not top-k capped)
- Per-comparison outputs include `geneset.meta.json`, `geneset.provenance.json`, `geneset.model.json`
- Output location: `version1_harmonizome/{COMPARISON}/`

### Version 2 — curated

Generated by `run/sbatch_04_curate_genesets.sh` using `src/curate_disease_genesets.py`.

- Base filter: padj < 0.05, logFC ≥ 1, valid HGNC gene symbol
- Concordance: where multiple controls exist (T-ALL: T21 + GTEx), genes must be upregulated across all controls (intersection)
- Score threshold: mean signed_neglog10padj ≥ 2.0 (approx. padj < 0.01); relaxed to ≥ 1.30 if fewer than 50 genes pass
- Maximum 200 genes per disease (safety cap)
- Upregulated genes only; downregulated sets separated as tissue/subtype markers
- Output location: `version2_curated/`

## Running the Pipeline

> **Note:** Scripts require SLURM. `PROJECT_DIR` and `DIG_DIR` in the sbatch scripts must be set to your local paths before running.

```bash
# Step 1: KidsFirst DE (8 comparisons)
sbatch run/sbatch_01_de_only.sh

# Step 2: CBTN DE (7 brain tumor comparisons)
sbatch run/sbatch_02_cbtn_de.sh

# Step 3: Extract Version 1 gene sets (harmonizome)
sbatch run/sbatch_03_extract_genesets.sh

# Step 4: Generate Version 2 curated gene sets
sbatch run/sbatch_04_curate_genesets.sh
```

Supporting scripts are in `src/`:

| Script | Purpose |
|--------|---------|
| `build_rsem_matrix.py` | Build per-study RSEM count matrix from individual files |
| `extract_gtex_counts.py` | Extract tissue-specific count matrix from GTEx GCT |
| `merge_study_matrices.py` | Merge multiple study matrices (pan-cancer categories) |
| `prepare_de_inputs.py` | Merge tumor + normal counts, create sample_metadata.tsv |
| `expand_gene_map_cbtn.py` | Expand ENSG→HGNC gene map for CBTN using mygene.info |
| `curate_disease_genesets.py` | Version 2 curation: concordance + score filter |
| `extract_immune_genesets.py` | Split DE results into immune / non-immune gene sets |

## Submission Package Structure

```
version1_harmonizome/
  {COMPARISON}/
    genesets.gmt                      ← all gene sets for this comparison
    manifest.tsv
    condition_tumor_vs_normal/
      geneset.tsv                     ← gene set members
      geneset.full.tsv                ← full ranked gene list
      geneset.meta.json
      geneset.provenance.json
      geneset.model.json
      run_summary.json
      run_summary.txt

version2_curated/
  disease_up.gmt                      ← primary deliverable: upregulated disease gene sets
  tissue_markers_dn.gmt               ← downregulated sets (tissue markers, QC reference)
  subtype_markers_dn.gmt
  manifest.tsv
  {LABEL}_disease_up.tsv              ← per-disease gene list with scores
  {LABEL}_tissue_dn.tsv
```
