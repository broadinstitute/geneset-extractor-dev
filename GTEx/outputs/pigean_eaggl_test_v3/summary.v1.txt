For the shared adipose signature `GTEx_AdiposeTissue_20-29_vs_30-39_Up`, the two locally generated libraries, `gtex_harmonizome_analysis_v1` and `gtex_no_harmonizome_analysis_v1`, were highly similar at the gene level, with Jaccard `0.692` and overlap coefficient `0.920`, whereas both were almost completely different from the reference set in `GTEx_XMT_2022-06-06_GTEx_Aging_Signatures_2021`, with pairwise Jaccards around `0.008-0.009` and only 3 genes shared across all three versions of the set. Consistent with that, the two local PIGEAN->EAGGL runs yielded broadly immune/inflammatory factor structure, led by `REACTOME_PD_1_SIGNALING` for the Harmonizome-derived set and `GSE42088_UNINF_VS_LEISHMANIA_INF_DC_24H_UP` for the no-Harmonizome set, while the reference GMT produced a qualitatively different top factor, `YAO_TEMPORAL_RESPONSE_TO_PROGESTERONE_CLUSTER_3`. The local EAGGL factors make reasonable biological sense for an adipose aging signature because immune and inflammatory remodeling is plausible in aging adipose tissue, although the factors look more immune-skewed than adipocyte-specific. By contrast, the reference GMT factors look less obviously appropriate for adipose tissue and are harder to reconcile with a coherent adipose-focused program. The main conclusion is that the same GTEx adipose set name maps to very different gene content in the reference GMT versus the locally regenerated libraries, and those upstream gene-set differences drive correspondingly different downstream EAGGL factorization results.
