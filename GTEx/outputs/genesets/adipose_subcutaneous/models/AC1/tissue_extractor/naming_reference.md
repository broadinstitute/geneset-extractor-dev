# Tissue-Level GMT Naming

This extractor emits one combined GMT for `adipose_subcutaneous` under model `AC1`.

Examples:
- `AC1__adipose_subcutaneous__pos`: genes with positive age-associated scores
- `AC1__adipose_subcutaneous__neg`: genes with negative age-associated scores

These are derived from one continuous-age regression across all retained tissue samples, not from separate age-bin contrasts.
