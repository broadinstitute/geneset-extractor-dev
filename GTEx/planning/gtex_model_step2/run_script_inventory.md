# GTEx Step 2 Run Script Inventory

- `prepare_gtex_tissue_inputs.sh`: convert one GTEx tissue counts GCT plus metadata into prepared DIG input tables
  path: `geneset-extractor-dev/GTEx/run/prepare_gtex_tissue_inputs.sh`
- `run_gtex_model.sh`: run one proposed model against one prepared tissue bundle
  path: `geneset-extractor-dev/GTEx/run/run_gtex_model.sh`
- `run_all_gtex_models.sh`: run all proposed models against one prepared tissue bundle
  path: `geneset-extractor-dev/GTEx/run/run_all_gtex_models.sh`
- `run_full_gtex_tissue_pipeline.sh`: prepare one tissue bundle from GTEx files and then run all proposed models
  path: `geneset-extractor-dev/GTEx/run/run_full_gtex_tissue_pipeline.sh`
