# Model ID Mapping

The provenance files in this directory were originally written with legacy age-binned model IDs `M1` through `M22`.

Current GTEx-local naming:

- `AB1` through `AB22`: age-binned contrast models
- `AC1` through `AC10`: continuous-age models
- `TV*`: reserved for future tissue-versus-reference models

For the files in this directory, the mapping is one-to-one:
