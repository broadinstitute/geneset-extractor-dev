# Age-Binned Runtime Script Inventory

- `build_tissue_inputs.sh`: convert one GTEx tissue counts GCT plus metadata into prepared DIG input tables
  path: `geneset-extractor-dev/GTEx/run/build_tissue_inputs.sh`
- `run_age_binned_model.sh`: run one proposed model against one prepared tissue bundle
  path: `geneset-extractor-dev/GTEx/run/run_age_binned_model.sh`
- `run_all_age_binned_models.sh`: run all proposed models against one prepared tissue bundle
  path: `geneset-extractor-dev/GTEx/run/run_all_age_binned_models.sh`
- `run_age_binned_pipeline.sh`: prepare one tissue bundle from GTEx files and then run all proposed models
  path: `geneset-extractor-dev/GTEx/run/run_age_binned_pipeline.sh`
