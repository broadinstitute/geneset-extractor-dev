# Script Updates for Reorganized Folder Structure

## Summary
All R and Python scripts in GTEx/VD have been updated to reference the new folder structure with `inputs/` and `outputs/` directories.

## Changes Applied

### 1. prepare_metadata.R
**Input file paths updated:**
- `"GTEx_Analysis_v8_Annotations_SampleAttributesDS.txt"` → `"inputs/GTEx_Analysis_v8_Annotations_SampleAttributesDS.txt"`
- `"GTEx_Analysis_v8_Annotations_SubjectPhenotypesDS.txt"` → `"inputs/GTEx_Analysis_v8_Annotations_SubjectPhenotypesDS.txt"`
- `"metadata.tsv"` → `"inputs/metadata.tsv"` (output now writes to inputs directory)

### 2. de_analysis_limma_voom.R
**Input file paths updated:**
- `"GTEx_Analysis_2017-06-05_v8_RNASeQCv1.1.9_gene_reads.gct"` → `"inputs/GTEx_Analysis_2017-06-05_v8_RNASeQCv1.1.9_gene_reads.gct"`
- `"metadata.tsv"` → `"inputs/metadata.tsv"`
- `"hgnc.txt"` → `"inputs/hgnc.txt"`

**Output directory updated:**
- Output folders now created under `outputs/` directory using `file.path("outputs", ...)` 
- Added `recursive = TRUE` to `dir.create()` for safety

### 3. batch_de_analysis.R
**Input file path updated:**
- `"comparisons.txt"` → `"inputs/comparisons.txt"`

### 4. collate_de_with_gmt.py
**Input file path updated:**
- GMT file: `current_dir / "GTEx_XMT_2022-06-06_GTEx_Aging_Signatures_2021.gmt"` → `current_dir / "inputs" / "GTEx_XMT_2022-06-06_GTEx_Aging_Signatures_2021.gmt"`

**Output directory updated:**
- DE results folder: `current_dir / folder_name` → `current_dir / "outputs" / folder_name`

### 5. batch_process_de_gmt.py
**Input file paths updated:**
- `current_dir / "comparisons.txt"` → `current_dir / "inputs" / "comparisons.txt"`
- `current_dir / "GTEx_XMT_2022-06-06_GTEx_Aging_Signatures_2021.gmt"` → `current_dir / "inputs" / "GTEx_XMT_2022-06-06_GTEx_Aging_Signatures_2021.gmt"`

**Output file paths updated:**
- Summary file: `current_dir / "gmt_analysis_summary.tsv"` → `current_dir / "outputs" / "gmt_analysis_summary.tsv"`
- DE results folder: `current_dir / folder_name` → `current_dir / "outputs" / folder_name`

## Execution Notes
- Scripts should be run from the GTEx/VD directory (not from inputs or outputs)
- All relative paths are now prefixed with `inputs/` for input files and `outputs/` for results
- The scripts maintain backward compatibility with the same command structure

## Testing Recommendations
1. Run `prepare_metadata.R` first to generate metadata.tsv in inputs/ directory
2. Test with a single comparison: `Rscript de_analysis_limma_voom.R "Tissue Age1 vs Age2"` (if testing single run)
3. Run batch analysis: `Rscript batch_de_analysis.R`
4. Process GMT results: `python collate_de_with_gmt.py "Tissue Age1 vs Age2"` or batch with `python batch_process_de_gmt.py`
