# Differential Expression Analysis using limma-voom on GTEx Data

## Overview

This document describes the differential expression analysis workflow implemented in `de_analysis_limma_voom.R`, designed for analyzing GTEx RNA-seq data using the limma-voom pipeline.

**Key Features**: 
- **Memory-optimized**: Loads only necessary samples from the ~56,000-gene GCT file (not all 10,000+ samples)
- **Robust metadata**: Parses comparison parameters early to identify target samples before reading large files
- **Selective column loading**: Reads only target sample columns from GCT using `colClasses` filtering
- **Gene annotation**: Maps Ensembl gene IDs to HGNC gene symbols for biological interpretation
- **Organized results**: Automatic folder creation by tissue and age comparison (e.g., `Thyroid_20-29_vs_40-49/`)
- **TSV output**: Tab-separated results for easy data analysis and import
- **Sorted results**: Genes sorted by logFC (upregulated on top, downregulated on bottom)
- **Publication-ready**: Includes volcano plots, MA plots, and diagnostic visualizations

## Workflow Steps

### Step 0: Data Preparation (Optional but Recommended)
- Run `prepare_metadata.R` to generate clean metadata.tsv in the `inputs/` directory
- This preprocessing step extracts tissue type and age from GTEx annotation files
- Creates a lightweight table for fast metadata queries
- **Command**: `cd GTEx/VD && Rscript prepare_metadata.R`
- **Output**: `inputs/metadata.tsv` (~2,402 samples with tissue and age annotations)

### Step 1: Library Setup & Configuration
- Set CRAN mirror and configure user library path
- Load required packages: limma, edgeR, tidyverse
- Load helper functions (e.g., `read_gct_selective()` for memory-efficient GCT loading)

### Step 2: Load Metadata & Parse Comparison Parameter
- Read clean metadata from `inputs/metadata.tsv` file
- **Parse comparison parameter** in format: `<tissue> <age_group1> vs <age_group2>`
- Example: `"Thyroid 20-29 vs 40-49"`
- Extract target tissue, age group 1, and age group 2
- Filter metadata to only samples matching tissue and age criteria

### Step 2.5: Create Output Directory
- Generate folder name from comparison parameter
- Format: `outputs/<tissue>_<age1>_vs_<age2>` (e.g., `outputs/Thyroid_20-29_vs_40-49/`)
- If no comparison specified: uses `outputs/results_all_samples/` folder
- All results, visualizations, and metadata saved to this folder
- Directory is created automatically if it doesn't exist

### Step 3: Selective Gene Expression Data Loading (Memory Efficient)
- Identify target samples from filtered metadata
- Read GCT file header to identify column positions
- **Load only target sample columns** using `colClasses` parameter
  - Set `colClasses="NULL"` for unneeded samples
  - Set `colClasses="numeric"` for target samples
  - Use `check.names=FALSE` to preserve sample ID formatting (dashes not converted to dots)
- Result: All 56,000+ genes × only needed samples in memory
- **Key advantage**: Reduces memory usage by 50-100x compared to loading full GCT

### Step 4: Quality Control - Low Abundance Filtering
- Remove low-abundance genes using CPM (counts per million) filtering
- Default: Keep genes where CPM ≥ 1 in at least 3 samples
- Rationale: Improves statistical power, reduces multiple testing burden
- **Typical retention**: ~50% of genes after filtering (28,500-32,000 genes retained)

### Step 5: Create Design Matrix
- Create factor variable for comparison groups
  - If tissue + age comparison specified: Create two age groups
  - Otherwise: Use tissue type or other metadata column as grouping factor
- Build model design matrix for statistical testing
- Ensure adequate sample sizes in each group

### Step 6: Voom Normalization & Transformation
- **Why Voom?**: Accounts for mean-variance relationship in RNA-seq count data
- **Process**:
  1. Calculate library size normalization factors (TMM method from edgeR)
  2. Convert counts to log2-CPM using normalized library sizes
  3. Calculate observation-level weights based on mean-variance trend
- **Output**: EList object with normalized log-expression values and precision weights

### Step 7: Linear Model Fitting & Statistical Testing
- Fit weighted linear model using Empirical Bayes regression (limma::lmFit)
- Apply contrast matrix to answer specific biological questions
- Apply empirical Bayes shrinkage to t-statistics (limma::eBayes)
- **Output**: Moderated t-statistics, p-values, and log-fold changes

### Step 8: Gene Symbol Annotation
- Load HGNC gene symbol database (optional hgnc.txt file)
- Strip version numbers from Ensembl gene IDs (e.g., ENSG00000116106.11 → ENSG00000116106)
- Map unversioned IDs to HGNC gene symbols
- Fallback to unversioned Ensembl ID if symbol not found in HGNC
- Result: Each gene has associated symbol for biological interpretation

### Step 9: Results Extraction & Annotation
- Extract top differentially expressed genes using limma::topTable
- Apply multiple testing correction (Benjamini-Hochberg FDR)
- Thresholds: 
  - Significant: FDR (adj.P.Val) < 0.05
  - Large effect: FDR < 0.05 AND |log2FC| > 1
- **Sort by logFC in descending order**:
  - Upregulated genes on top (positive logFC, highest first)
  - Downregulated genes on bottom (negative logFC, lowest last)
- Merge results with gene symbols using annotated gene list

### Step 10: Visualization
- **MDS Plot**: Multidimensional scaling of samples (voom_diagnostic_plots.pdf)
- **Volcano Plot**: logFC vs. -log10(adj.P.Val) with significance threshold (volcano_plot.pdf)
- **MA Plot**: Average expression vs. logFC highlighting significant genes (ma_plot.pdf)
- **Color scheme**: Significant genes highlighted, others gray

### Step 11: Results Export & Summary
- **de_genes_all.tsv**: All genes with statistics (gene_symbol, gene_id, logFC, AveExpr, t, P.Value, adj.P.Val), sorted by logFC
- **de_genes_significant.tsv**: Significant genes only (FDR < 0.05), sorted by logFC
- **de_genes_significant_fc1.tsv**: Significant with effect size (FDR < 0.05 AND |logFC| > 1), sorted by logFC
- **sample_metadata.tsv**: Processed sample information for reference
- Console output: Summary statistics and top 10 genes

## Key Parameters & Customization

### User-Configurable Parameters

At the top of the script, you'll find:

```R
# Specify comparison in format: "<tissue> <age_group1> vs <age_group2>"
comparison_param <- "Thyroid 20-29 vs 40-49"

# Alternative: compare by sex, age, tissue, or tissue+age
comparison_type <- "TISSUE_AGE"
```

### Tissue + Age Group Comparisons

This is the most powerful parameter. Use format: `<tissue> <age_group1> vs <age_group2>`

**Examples:**
```R
comparison_param <- "Thyroid 20-29 vs 40-49"        # Thyroid age comparison
comparison_param <- "Heart 30-39 vs 70-79"          # Heart across distant ages
comparison_param <- "Blood 50-59 vs 60-69"          # Blood adjacent ages
comparison_param <- "Brain 40-49 vs 50-59"          # Brain frontal cortex
```

Age groups available in GTEx: 20-29, 30-39, 40-49, 50-59, 60-69, 70-79

The script will automatically:
- Filter to the specified tissue
- Create two groups based on age ranges
- Generate comparison statistics between the age groups
- Update filtering to ensure adequate sample sizes

### Adjusting Filtering Thresholds
```R
cpm_threshold <- 1          # CPM cutoff
n_samples_threshold <- 3    # Min samples above threshold
```

### Default Tissue Comparison (Broad)
Set `comparison_param <- ""` or `NULL` to compare all tissues:
```R
comparison_param <- NULL
sample_metadata$group <- as.factor(sample_metadata$tissue)
```

### Sex-Based Comparison

To compare by biological sex instead:
```R
comparison_param <- NULL
sample_metadata$group <- as.factor(sample_metadata$SEX)
```

### Adjusting Statistical Thresholds
```R
# In results extraction:
sig_genes <- results[results$adj.P.Val < 0.05, ]  # Change 0.05 for different FDR
sig_genes_fc <- results[results$adj.P.Val < 0.05 & abs(results$logFC) > 1, ]  # Adjust logFC threshold
```

### Complex Contrasts
For multi-group comparisons (e.g., 3+ tissues), modify contrast matrix:
```R
contrast_matrix <- makeContrasts(
  tissue1_vs_tissue2 = tissue1 - tissue2,
  tissue1_vs_tissue3 = tissue1 - tissue3,
  tissue2_vs_tissue3 = tissue2 - tissue3,
  levels = design
)
```

## Results Interpretation

### Result Files Organization
Results are automatically organized in the `outputs/` directory in tissue-specific folders. Run the script multiple times with different comparison parameters to generate separate folders:
```
outputs/
├── Thyroid_20-29_vs_40-49/
│   ├── de_genes_all.tsv
│   ├── de_genes_significant.tsv
│   ├── de_genes_significant_fc1.tsv
│   ├── de_genes_with_gmt.tsv
│   ├── sample_metadata.tsv
│   ├── volcano_plot.pdf
│   ├── ma_plot.pdf
│   └── voom_diagnostic_plots.pdf
├── Heart_30-39_vs_60-69/
│   ├── de_genes_all.tsv
│   └── ... (same structure)
└── gmt_analysis_summary.tsv
```

### logFC (log2 Fold Change)
- **Positive values (top of file)**: Genes upregulated in group 2 vs group 1
- **Negative values (bottom of file)**: Genes downregulated in group 2 vs group 1
- **Magnitude**: |logFC| > 1 represents ~2-fold change
- **Sorted order**: Results always sorted largest to smallest logFC for easy identification of most regulated genes

### P-values
- `P.Value`: Nominal p-value from t-test
- `adj.P.Val`: Benjamini-Hochberg adjusted p-value (recommended)
- Use adj.P.Val to control false discovery rate

### AveExpr
- Average log2-CPM expression across all samples
- Useful for filtering low-abundance genes

## Batch Analysis

For running multiple comparisons automatically, use `batch_de_analysis.R`:

### Setup

Create a `comparisons.txt` file with one comparison per line (format: `<tissue> <age_group1> vs <age_group2>`):

```
Thyroid 20-29 vs 40-49
Heart 30-39 vs 60-69
Blood 50-59 vs 70-79
Kidney 20-29 vs 40-49
...
```

### Running Batch Analysis

```bash
Rscript batch_de_analysis.R
```

This will:
1. Read all comparisons from `comparisons.txt`
2. Run DE analysis for each comparison sequentially
3. Create separate output folders for each tissue/age pair
4. Skip comparisons with insufficient samples (< 2 per group)
5. Report summary of successful, skipped, and failed comparisons
6. Continue processing even if individual comparisons fail

### Batch Analysis Features

- **Progress tracking**: Shows real-time progress (`[N/M] Running: ...`)
- **Timing information**: Displays elapsed time and estimated completion
- **Error handling**: Gracefully skips insufficient samples, catches and reports errors
- **Summary reporting**: Shows:
  - Total comparisons processed
  - Number successful
  - Number skipped (insufficient samples)
  - Number failed (actual errors)
  - Total runtime
  - Lists of skipped and failed comparisons

### Expected Runtime

- Per comparison: ~15-25 minutes
- Batch of 100+ comparisons: ~24-40 hours depending on group sizes

## Expected Runtime (Single Comparison)

- Data loading: ~2-5 minutes (depends on disk speed)
- Processing & analysis: ~10-20 minutes
- Total: ~15-25 minutes

## Advanced Extensions

1. **Batch Processing**: Use `batch_de_analysis.R` to run 100+ comparisons sequentially with error handling
2. **Batch Effect Correction**: Add `SMNABTCH` (batch) to design matrix
3. **Covariate Adjustment**: Include `RIN` (RNA integrity) or `SMTSISCH` (ischemic time)
4. **Gender Stratification**: Fit separate models by sex
5. **Pathway Analysis**: Use results with `fgsea`, `clusterProfiler`, or `MSigDB`
6. **Coexpression Analysis**: Use `WGCNA` on significant genes

## Troubleshooting

**Issue**: "Package not found" error
- **Solution**: Run `Rscript install_packages.R`

**Issue**: Memory errors on large datasets
- **Solution**: The script is already optimized for memory by loading only target samples. If you still encounter issues:
  - Specify a comparison parameter to reduce sample count (e.g., "Thyroid 20-29 vs 40-49")
  - Analyze one tissue at a time
  - Consider parallelizing across tissues

**Issue**: No significant genes found
- **Solution**: Check design matrix; verify groups are well-distributed; lower FDR threshold cautiously

**Issue**: Output folder not created
- **Solution**: The folder is created automatically based on `comparison_param`. Check that the parameter is properly specified (e.g., "Thyroid 20-29 vs 40-49") and R has write permissions in the current working directory

**Issue**: Some comparisons are skipped during batch analysis
- **Solution**: This is expected. Comparisons are skipped when they don't have at least 2 samples in each group. Check the batch summary for details on which comparisons were skipped due to insufficient samples. You can verify tissue/age availability by checking the metadata.tsv file.
