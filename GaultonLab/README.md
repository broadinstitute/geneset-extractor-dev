# GaultonLab submission wrapper

This library imports twelve supplied, externally generated GMTs unchanged. They
were generated by the GaultonLab LIANA cell-cell communication pipeline:
<https://github.com/kjgaulton/liana-ccc-pipeline>. No repository-side
scientific reconstruction is claimed or performed.

The library has four tissue partitions (`heart`, `liver`, `lung`, `spleen`) and
three shared model families: `HZ1` combined signal genes, `HZ2` incoming
receptor genes, and `HZ3` outgoing ligand genes. The recorded SHA-256 digest
for every input is verified before it is copied.

Run the direct import and standard sidecar refresh:

```bash
SUBMISSION_WORK_DIR=/path/to/output DIG_REPO=../dig-gene-set-extractors \
  bash reproduction/reproduce.sh --full
SUBMISSION_WORK_DIR=/path/to/output DIG_REPO=../dig-gene-set-extractors \
  bash run/refresh_submission_models.sh
```

Set `GAULTONLAB_GMT_DIR` when the supplied GMT directory is not at
`submissions/cfde_legacy/GaultonLab`.

For renamed or separately located inputs, copy
`config/input_gmt_map.example.tsv`, set the `input_gmt` path for each
`partition_id`/`model_id` pair, then export its path as
`GAULTONLAB_GMT_MAP_TSV`. Relative paths resolve against the map file's
directory; absolute paths are also supported. The per-task SHA-256 check in
`config/task_manifest.tsv` still applies.

For Apptainer-backed SGE submission, set `APPTAINER_IMAGE`, `DIG_REPO`, and
`SUBMISSION_WORK_DIR`, then use a safe dry run or submit the 12-task array:

```bash
bash run/submit_submission_models_cluster_apptainer.sh --full
bash run/submit_submission_models_cluster_apptainer.sh --full --submit
```

Refresh the completed model metadata and provenance with:

```bash
bash run/submit_submission_models_cluster_apptainer.sh \
  --full --refresh-metadata-and-provenance --submit
```
