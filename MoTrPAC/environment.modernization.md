# MoTrPAC modernization environment

Full `TR*`, `TW*`, `HZ2`, and `HZ3` reproduction requires the pinned DIG
checkout plus `Rscript` with `edgeR` and `limma`. The HZ1 smoke fixture uses
the DIG released-DEA workflow and requires only the Python dependencies
already declared by DIG. The standard production launcher is Apptainer.
